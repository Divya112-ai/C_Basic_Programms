# Divya's C / C++ Programs Collection

This folder contains a collection of C and C++ lab/practice programs, organized by
file type for easy navigation. The programs are written in the classic
Turbo C/C++ style (`conio.h`, `clrscr()`, `getch()`) and cover fundamental
programming concepts such as conditionals, loops, arrays, strings, structures,
and basic data processing.

## 🧾 Naming Convention

All files follow the pattern `PRO<number>.<extension>`, where the number
reflects the order in which the programs were written/practiced
(e.g., `PRO1`, `PRO2`, ... `PRO223`). The same number may appear in more
than one folder — for example, `PRO171.C` in `C_Programs` and a `.BAK`
backup of an earlier save in `Backup_Files` — since they represent the
same program at different stages.

## 🗒️ About the `.BAK` Files

`.BAK` files are automatic backups created by the Turbo C/C++ compiler
each time a `.C` or `.CPP` file is saved — they hold the previous version
of the program before the last edit. They aren't required to compile or
run anything, but have been kept (in `Backup_Files`) in case any earlier
version of a program is ever needed for reference.

## ▶️ How to Run These Programs

These programs were originally written for the Turbo C/C++ compiler
(DOS-based). To run them today, you can either:

1. **Use an emulator** – Install Turbo C++ via DOSBox, or
2. **Use a modern compiler** – Most programs will run with minor tweaks
   (e.g., replace `conio.h`/`clrscr()`/`getch()` calls, since these are
   Turbo C/C++-specific and not supported by GCC/G++ on modern systems).
